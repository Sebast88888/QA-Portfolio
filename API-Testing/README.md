# API Testing Project

## Objective

Validate REST API endpoints using functional testing techniques.

## Scope

The project covers:

* GET requests
* POST requests
* PUT requests
* DELETE requests
* Response validation
* Status code verification

## Tools

* Postman
* JSONPlaceholder
* GitHub

## API Used

https://jsonplaceholder.typicode.com/

## Test Coverage

* Endpoint validation
* Response structure validation
* Status code verification
* CRUD operations testing
